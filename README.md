# 🚀 Project Management System

A full-stack Project Management application built using **Spring Boot** for the backend and **MySQL** for data persistence.  
The system supports complete CRUD operations for managing projects, tasks, statuses, types, and team members.

---

## 📌 Features

- Create, update, delete and manage projects
- Manage tasks/items within projects
- Track project status and type
- Team member management
- RESTful API architecture
- Layered backend structure
- MySQL database integration

---

## 🛠 Tech Stack

### Backend
- Java 17 / 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven

### Frontend
- Thymeleaf
- Vue.js 2
- Axios
- Bootstrap
- HTML / CSS

---

## 🏗 Architecture

Controller → Service → Repository → Database  

The project follows a clean layered architecture:
- **Controller Layer** – Handles HTTP requests
- **Service Layer** – Business logic
- **Repository Layer** – Database access using JPA
- **Entity Layer** – Data models mapped to MySQL tables
